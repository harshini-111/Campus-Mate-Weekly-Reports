## About the Project

Campus Mate is a proposed campus-focused web application developed as part of the Java Project-Based Learning (PBL) programme.

This repository contains the weekly project reports documenting the research, interface design, frontend development, responsive design, integration support, testing, and documentation activities associated with the project.
